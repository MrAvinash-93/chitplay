# ChitPlay: 47 free games in your browser

**[▶ Play now at chitplay.com](https://www.chitplay.com/)**

ChitPlay is a free online games site: Ludo, Chess, Carrom, Call Break, racing, party games and more, 47 in all. There is nothing to download and no sign-up. Play against the computer, with friends online, or pass one phone around. It works on phones, tablets and computers, and keeps working offline once it has loaded.

## How you can play

- **Against the computer:** every game has computer players, so you can start straight away.
- **With friends:** host a room and share the link or QR code. Friends join from their own phones by scanning it or typing the code.
- **On one phone:** pass the phone around. A cover screen hides your cards or chit while it changes hands.
- **Offline:** after the first visit, the games keep working without a connection.

The site is in English, with game pages in Hindi, Hinglish, Bangla, Urdu, Nepali, Spanish, Portuguese, French, German, Italian, Russian, Turkish, Indonesian, Japanese, Korean and Chinese.

## About this repository

This repository holds the source of [chitplay.com](https://www.chitplay.com/), served with GitHub Pages. The site is plain HTML, CSS and JavaScript modules with no build step, and the 3D scenes use three.js.

Run it locally:

```bash
python serve.py      # then open http://127.0.0.1:8000
node --test tests/*.test.js
```

Notes for development are in [tools/DEV-NOTES.md](tools/DEV-NOTES.md).
