Faltgeschichte (Consequences)

Anleitung auf Deutsch

Schreibt eine Geschichte Zeile für Zeile auf gefaltetem Papier und faltet sie dann auf.

English name: Consequences

So wird gespielt

  1. Reihum fügt jeder einen Satz für den gezeigten Teil hinzu, ohne die vorherigen zu sehen.
  2. Mit Freunden tippst du deine eigenen Sätze. An einem Tisch mit Fremden wählst du aus Sätzen, die wir geschrieben haben, damit niemand etwas Gemeines schicken kann.
  3. Sieben Teile ergeben eine Geschichte: wer, traf wen, wo, was jeder sagte, was passierte und was die Welt dazu sagte.
  4. Dann entfaltet sich die Geschichte, und alle lesen sie.

Punkte

Es gibt keine Punkte: Die beste Geschichte gewinnt den Raum.

Wer gewinnt

Alle gewinnen, wenn die Geschichte den ganzen Tisch zum Lachen bringt.

Häufige Fragen

Woher kommt der Name?

Es ist ein traditionelles Gesellschaftsspiel auf gefaltetem Papier, und die letzte Zeile erzählt „die Folge“.

Können Fremde mir schreiben?

Nein. An öffentlichen Tischen wählen alle aus unserer festen Liste von Sätzen.

So kannst du spielen

  • Als Gast: Keine Anmeldung, kein Login. Namen wählen und sofort spielen.
  • Gegen den Computer: Wenn niemand da ist, besetzen Computerspieler die freien Plätze. Leicht, normal oder schwer.
  • Online: Setz dich an einen öffentlichen Tisch mit Spielern aus aller Welt.
  • Mit Freunden in der Nähe: Starte das Spiel auf einem Handy und teile den Code oder QR-Code. Deine Freunde machen auf ihren Handys mit.
  • Auf einem Handy: Reicht das Handy reihum weiter: ein Gerät genügt für die ganze Familie.
