Vier in einer Reihe (Four in a Row)

Anleitung auf Deutsch

Steine einwerfen und vor dem anderen vier in eine Reihe bringen.

English name: Four in a Row

So wird gespielt

  1. Abwechselnd wirft jeder eine Scheibe in eine Spalte, in der noch Platz ist.
  2. Die Scheibe fällt auf den untersten freien Platz dieser Spalte.
  3. Bilde eine Reihe aus vier deiner Scheiben, waagerecht, senkrecht oder diagonal, und du gewinnst sofort.

Punkte

Eine Partie endet mit Sieg oder Unentschieden. Die Ergebnistabelle zeigt 1 für den Sieger.

Wer gewinnt

Die erste Viererreihe gewinnt. Ist das Gitter voll ohne Reihe, ist es unentschieden.

Häufige Fragen

Wer fängt an?

Der erste Spieler am Tisch. Anfangen ist ein Vorteil, also wechselt euch über mehrere Partien ab.

Hat das Gitter die Standardgröße?

Ja: sieben Spalten und sechs Reihen.

So kannst du spielen

  • Als Gast: Keine Anmeldung, kein Login. Namen wählen und sofort spielen.
  • Gegen den Computer: Wenn niemand da ist, besetzen Computerspieler die freien Plätze. Leicht, normal oder schwer.
  • Online: Setz dich an einen öffentlichen Tisch mit Spielern aus aller Welt.
  • Mit Freunden in der Nähe: Starte das Spiel auf einem Handy und teile den Code oder QR-Code. Deine Freunde machen auf ihren Handys mit.
  • Auf einem Handy: Reicht das Handy reihum weiter: ein Gerät genügt für die ganze Familie.
