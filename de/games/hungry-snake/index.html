Anleitung auf Deutsch

Snacks essen, länger werden und nirgends anstoßen. Die klassische Schlange.

English name: Hungry Snake

So wird gespielt

  1. Lenk deine Schlange nach oben, unten, links oder rechts. Sie bleibt nie stehen.
  2. Friss einen Snack für einen Punkt und werd länger.
  3. Stößt du gegen eine Wand, dich selbst oder eine andere Schlange, ist dein Spiel vorbei.
  4. Mit anderen bekommt die letzte Schlange, die sich noch bewegt, 3 Bonuspunkte.

Punkte

Ein Punkt pro Snack, dazu 3 für die letzte übrige Schlange.

Wer gewinnt

Allein schlägst du deinen Rekord. Mit anderen gewinnt die höchste Punktzahl.

Häufige Fragen

Wird es schwerer?

Ja. Alle sechs Samosas kommt ein neues Level: Die Schlangen werden schneller, und eine Ziegelmauer entsteht auf dem Feld.

Wie viele können spielen?

Bis zu vier, der Computer füllt freie Plätze.

So kannst du spielen

  • Als Gast: Keine Anmeldung, kein Login. Namen wählen und sofort spielen.
  • Gegen den Computer: Wenn niemand da ist, besetzen Computerspieler die freien Plätze. Leicht, normal oder schwer.
  • Online: Setz dich an einen öffentlichen Tisch mit Spielern aus aller Welt.
  • Mit Freunden in der Nähe: Starte das Spiel auf einem Handy und teile den Code oder QR-Code. Deine Freunde machen auf ihren Handys mit.
  • Auf einem Handy: Reicht das Handy reihum weiter: ein Gerät genügt für die ganze Familie.
