Was sagt die Mehrheit? (Majority Vote)

▶ Jetzt gratis spielen

  • 👥 3–10 Spieler
  • Partyspiele
  • 🆓

Anleitung auf Deutsch

Rate, was die meisten am Tisch wählen werden.

English name: Majority Vote

So wird gespielt

  1. Eine Frage öffnet sich mit ein paar möglichen Antworten.
  2. Jeder wählt geheim die Antwort, von der er glaubt, dass die meisten sie wählen.
  3. Wenn alle gewählt haben, werden die Summen als Balken gezeigt.
  4. Alle, die die beliebteste Antwort gewählt haben, bekommen einen Punkt.

Punkte

Ein Punkt jedes Mal, wenn du die Antwort der Mehrheit wählst. Liegen zwei Antworten gleichauf vorn, zählen beide.

Wer gewinnt

Wer nach der letzten Frage die meisten Punkte hat, gewinnt.

Häufige Fragen

Ist meine Wahl geheim?

Ja. Nur die Summen werden gezeigt.

Was passiert bei Gleichstand?

Haben zwei Antworten gleich viele Stimmen, zählen beide als Mehrheit.

So kannst du spielen

  • Als Gast: Keine Anmeldung, kein Login. Namen wählen und sofort spielen.
  • Gegen den Computer: Wenn niemand da ist, besetzen Computerspieler die freien Plätze. Leicht, normal oder schwer.
  • Online: Setz dich an einen öffentlichen Tisch mit Spielern aus aller Welt.
  • Mit Freunden in der Nähe: Starte das Spiel auf einem Handy und teile den Code oder QR-Code. Deine Freunde machen auf ihren Handys mit.
  • Auf einem Handy: Reicht das Handy reihum weiter: ein Gerät genügt für die ganze Familie.
