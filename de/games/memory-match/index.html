Gedächtnisspiel (Memory Match)

▶ Jetzt gratis spielen

  • 👥 2–4 Spieler
  • Papier-und-Stift-Spiele
  • 🆓

Anleitung auf Deutsch

Zwei Karten aufdecken und merken. Die Paare gehen an das beste Gedächtnis.

English name: Memory Match

So wird gespielt

  1. Tipp in deinem Zug auf zwei Karten, um sie umzudrehen. Alle Spieler können sie sehen.
  2. Passen sie zusammen, behältst du das Paar und bist noch mal dran.
  3. Passen sie nicht, drehen sie sich zu Beginn des nächsten Zuges wieder um, und der Nächste ist dran.

Punkte

Jedes Paar zählt einen Punkt.

Wer gewinnt

Sind alle Paare gefunden, gewinnt, wer die meisten hat. Liegen alle gleichauf, ist es unentschieden.

Häufige Fragen

Schummeln die Computerspieler?

Nein. Sie kennen nur die Karten, die schon aufgedeckt wurden, und vergessen sogar einige davon.

Wie viele Paare gibt es?

Zwölf Paare, auf vierundzwanzig Karten.

So kannst du spielen

  • Als Gast: Keine Anmeldung, kein Login. Namen wählen und sofort spielen.
  • Gegen den Computer: Wenn niemand da ist, besetzen Computerspieler die freien Plätze. Leicht, normal oder schwer.
  • Online: Setz dich an einen öffentlichen Tisch mit Spielern aus aller Welt.
  • Mit Freunden in der Nähe: Starte das Spiel auf einem Handy und teile den Code oder QR-Code. Deine Freunde machen auf ihren Handys mit.
  • Auf einem Handy: Reicht das Handy reihum weiter: ein Gerät genügt für die ganze Familie.
