Anleitung auf Deutsch

Bilde Dreierreihen und nimm Steine weg, in diesem uralten Strategiespiel.

English name: Nine Men’s Morris

So wird gespielt

  1. Setzen: Abwechselnd setzt jeder einen Stein auf einen freien Punkt, bis beide je neun gesetzt haben.
  2. Ziehen: Danach schiebt jeder abwechselnd einen Stein entlang einer Linie auf einen freien Nachbarpunkt.
  3. Immer wenn du eine neue Dreierreihe bildest, eine Mühle, nimmst du einen gegnerischen Stein weg. Steine in einer Mühle sind geschützt, außer alle stehen in Mühlen.
  4. Springen: Hast du nur noch drei Steine, dürfen sie auf jeden freien Punkt springen.

Punkte

Eine Partie endet mit Sieg oder Remis. Die Ergebnistabelle zeigt 1 für den Sieger.

Wer gewinnt

Du gewinnst, wenn der andere nur noch zwei Steine oder keinen legalen Zug hat. Fünfzig Züge je Seite ohne Schlag sind ein Remis.

Häufige Fragen

Warum heißt es Nine Men's Morris?

Jeder Spieler hat neun Steine, „men“. „Morris“ kommt wohl von einem alten Wort für die Spielsteine. Auf Deutsch heißt das Spiel Mühle.

Was ist Springen?

Ein Spieler mit nur noch drei Steinen darf einen Stein auf jeden freien Punkt setzen, nicht nur auf einen Nachbarpunkt.

So kannst du spielen

  • Als Gast: Keine Anmeldung, kein Login. Namen wählen und sofort spielen.
  • Gegen den Computer: Wenn niemand da ist, besetzen Computerspieler die freien Plätze. Leicht, normal oder schwer.
  • Online: Setz dich an einen öffentlichen Tisch mit Spielern aus aller Welt.
  • Mit Freunden in der Nähe: Starte das Spiel auf einem Handy und teile den Code oder QR-Code. Deine Freunde machen auf ihren Handys mit.
  • Auf einem Handy: Reicht das Handy reihum weiter: ein Gerät genügt für die ganze Familie.
