Anleitung auf Deutsch

Eine Zahl blitzt auf und verschwindet. Tippe sie zurück. Jede Runde eine Ziffer mehr: Wie viele schaffst du?

English name: Number Memory

So wird gespielt

  1. Eine Zahl erscheint kurz. Der Balken darunter zeigt, wie lange sie bleibt.
  2. Ist sie weg, tippe die Zahl auf dem Ziffernfeld (oder der Tastatur) und drück ✓. Du hast bis zu 15 Sekunden.
  3. Richtig: Die nächste Zahl hat eine Ziffer mehr. Falsch: Du verlierst ein Herz. Drei Herzen weg, und du bist raus.
  4. Jedes Handy behält, was sein Spieler tippt, und sendet die ganze Antwort mit ✓; die Handys der Freunde sehen die Zahl nie, während geantwortet wird.

Punkte

Eine richtige Antwort bringt zehn Punkte pro Ziffer: Eine 7-stellige Zahl ist 70 wert. Medaillen bei 70, 150, 250 und 400 Punkten.

Wer gewinnt

Allein merkst du dir die längste Zahl, die du kannst. Mit Freunden gewinnen die meisten Punkte; das Spiel endet, wenn alle raus sind oder der Letzte im Spiel schon vorn liegt.

Häufige Fragen

Wie viele Ziffern können sich die meisten merken?

Etwa sieben, plus minus zwei. Mit Übung und Gruppieren schaffen manche zehn und mehr.

Können Freunde schummeln, indem sie die Zahl ansehen?

Nein. Während geantwortet wird, bekommen die anderen Handys Punkte statt der Zahl.

So kannst du spielen

  • Als Gast: Keine Anmeldung, kein Login. Namen wählen und sofort spielen.
  • Gegen den Computer: Wenn niemand da ist, besetzen Computerspieler die freien Plätze. Leicht, normal oder schwer.
  • Online: Setz dich an einen öffentlichen Tisch mit Spielern aus aller Welt.
  • Mit Freunden in der Nähe: Starte das Spiel auf einem Handy und teile den Code oder QR-Code. Deine Freunde machen auf ihren Handys mit.
  • Auf einem Handy: Reicht das Handy reihum weiter: ein Gerät genügt für die ganze Familie.
