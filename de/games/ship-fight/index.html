Anleitung auf Deutsch

Zwei Schiffe, Kanonen im Dauerfeuer. Ausweichen, zielen, den Freund versenken.

English name: Ship Fight

So wird gespielt

  1. Fahr dein Schiff überall in deiner Hälfte des Meeres herum. Seine Kanone feuert ungefähr jede Sekunde von selbst auf das andere Schiff.
  2. Jedes Schiff hält fünf Treffer aus. Felsen halten Schüsse auf, also nutze sie als Deckung.
  3. In der Mitte tauchen Kisten auf: Ein Herz repariert dein Schiff, und die Kanonenkiste gibt fünf Dreifachschüsse.
  4. Dauert eine Runde zu lange, zermürbt ein Sturm die Schiffe, angefangen bei dem mit weniger Leben.

Punkte

Das andere Schiff zu versenken gewinnt die Runde.

Wer gewinnt

Wer zuerst drei Runden gewinnt, gewinnt das Match.

Häufige Fragen

Wie spielen zwei?

Auf einer Tastatur nimmt einer W A S D und die Leertaste, der andere die Pfeiltasten und Enter. Zwei Gamepads gehen auch, eins für jeden.

Kann ich allein spielen?

Ja, gegen einen Computerspieler, der Fehler macht wie ein Mensch.

So kannst du spielen

  • Als Gast: Keine Anmeldung, kein Login. Namen wählen und sofort spielen.
  • Gegen den Computer: Wenn niemand da ist, besetzen Computerspieler die freien Plätze. Leicht, normal oder schwer.
  • Online: Setz dich an einen öffentlichen Tisch mit Spielern aus aller Welt.
  • Mit Freunden in der Nähe: Starte das Spiel auf einem Handy und teile den Code oder QR-Code. Deine Freunde machen auf ihren Handys mit.
  • Auf einem Handy: Reicht das Handy reihum weiter: ein Gerät genügt für die ganze Familie.
