Four in a Row (Four in a Row)

▶ Abhi free khelo

  • 👥 2 players
  • Board games
  • 🆓

Hinglish guide

Gotiyan giraao aur doosre se pehle chaar ek line mein lagao.

English name: Four in a Row

Kaise khelein

  1. Baari baari kisi bhi khaali column mein ek goti daalo.
  2. Goti us column ki sabse neeche khaali jagah pe girti hai.
  3. Apni chaar gotiyan line mein laao, aadi, khadi ya tirchhi, aur turant jeeto.

Points kaise milte hain

Game jeet ya draw pe khatam. Result mein jeetne wale ko 1.

Kaun jeetta hai

Pehli chaar ki line jeetti hai. Grid bhar gaya aur line nahi bani to draw.

Pehle kaun chalta hai?

Table pe pehla player. Pehle chalna faayde ka hai, isliye kai games mein baari-baari se shuru karo.

Kya grid normal size ka hai?

Haan: saat column aur chhe lines.

Khelne ke tareeke

  • Guest ban kar khelo: Koi sign-up ya login nahi. Naam chuno aur turant khelo.
  • Computer ke saath: Jab koi saath na ho, computer players khaali jagah bhar dete hain. Easy, Normal ya Hard chuno.
  • Online khelo: Duniya bhar ke players ke saath ek public table par baitho.
  • Dosto ke saath Nearby: Ek phone par game shuru karo aur code ya QR code share karo. Dost apne phone se jud jaate hain.
  • Ek hi phone par: Phone baari-baari sabko do. Poori family ke liye ek device kaafi hai.
