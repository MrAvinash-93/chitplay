Memory Match (Memory Match)

▶ Abhi free khelo

  • 👥 2–4 players
  • Pen aur paper games
  • 🆓

Hinglish guide

Do tiles palto aur yaad rakho. Jodiyan sabse tez yaaddasht wale ki.

English name: Memory Match

Kaise khelein

  1. Apni baari pe do tiles dabake palto. Sab players unhe dekh sakte hain.
  2. Match hua to jodi tumhari aur phir se baari.
  3. Match nahi hua to agle player ki baari shuru hote hi woh palat jaate hain, aur baari aage.

Points kaise milte hain

Har jodi ek point.

Kaun jeetta hai

Saari jodiyan mil gayi to jiske paas sabse zyada woh jeeta. Sab barabar to draw.

Aksar pooche jaane wale sawaal

Kya computer players beimaani karte hain?

Nahi. Wo sirf palti gayi tiles jaante hain, aur unmein se kuch bhool bhi jaate hain.

Kitne jode hote hain?

Chaubees tiles pe baarah jode.

Khelne ke tareeke

  • Guest ban kar khelo: Koi sign-up ya login nahi. Naam chuno aur turant khelo.
  • Computer ke saath: Jab koi saath na ho, computer players khaali jagah bhar dete hain. Easy, Normal ya Hard chuno.
  • Online khelo: Duniya bhar ke players ke saath ek public table par baitho.
  • Dosto ke saath Nearby: Ek phone par game shuru karo aur code ya QR code share karo. Dost apne phone se jud jaate hain.
  • Ek hi phone par: Phone baari-baari sabko do. Poori family ke liye ek device kaafi hai.
