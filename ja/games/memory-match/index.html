神経衰弱 (Memory Match)

▶ 今すぐ無料で遊ぶ

  • 👥 2–4 人
  • 紙とペンのゲーム
  • 🆓

日本語ガイド

2枚めくって覚えよう。ペアは一番記憶力のいい人のもの。

English name: Memory Match

遊び方

  1. 自分の番に、カードを2枚タップしてめくります。全員に見えます。
  2. そろったらペアをもらい、もう一度めくれます。
  3. そろわなければ、次の人の番の始めに裏に戻り、番が移ります。

得点

ペア1組につき1点です。

勝ち方

ペアが全部見つかったら、ペアがいちばん多い人の勝ち。全員同じなら引き分けです。

よくある質問

コンピューターはずるをしますか？

しません。めくられたカードしか知らず、いくつかは忘れてしまいます。

ペアはいくつありますか？

24枚のカードで12ペアです。

遊び方

  • ゲストで: 登録もログインもなし。名前を選んですぐに遊べます。
  • コンピューターと: 誰もいなくても、空いた席にはコンピューターが座ります。かんたん・ふつう・むずかしいから選べます。
  • オンラインで: 世界中のプレイヤーがいる公開テーブルに参加できます。
  • 近くの友だちと: 1台のスマホでゲームを始めてコードかQRコードを共有。友だちは自分のスマホで参加します。
  • 1台のスマホで: 順番にスマホを回せば、家族みんなで1台で遊べます。
