数字記憶テスト (Number Memory)

▶ 今すぐ無料で遊ぶ

  • 👥 1–4 人
  • 紙とペンのゲーム
  • 🆓

日本語ガイド

数字が一瞬出て消えます。打ち返そう。毎回1桁ずつ長くなる：何桁まで覚えられる？

English name: Number Memory

遊び方

  1. 数字が少しの間だけ表示されます。下のバーで残り時間がわかります。
  2. 消えたら、キーパッド（またはキーボード）で数字を入力して ✓ を押します。最大15秒です。
  3. 正解なら次の数字は1桁長くなります。不正解ならハートが1つ減り、3つなくなると脱落です。
  4. 入力はそれぞれのスマホに残り、✓ で答え全体が送られます。答えている間、友だちのスマホには数字が送られません。

得点

正解は1桁につき10点です（7桁なら70点）。70、150、250、400点でメダルです。

勝ち方

ひとりなら、覚えられる最長の数字を目指します。友だちとなら点数がいちばん多い人の勝ち。全員脱落するか、最後に残った人がすでにトップなら終了です。

よくある質問

多くの人は何桁覚えられますか？

だいたい7桁前後（±2）です。練習や区切って覚えるコツで、10桁以上覚える人もいます。

友だちが数字を見てズルできますか？

できません。答えている間、ほかのスマホには数字の代わりに点が送られます。

遊び方

  • ゲストで: 登録もログインもなし。名前を選んですぐに遊べます。
  • コンピューターと: 誰もいなくても、空いた席にはコンピューターが座ります。かんたん・ふつう・むずかしいから選べます。
  • オンラインで: 世界中のプレイヤーがいる公開テーブルに参加できます。
  • 近くの友だちと: 1台のスマホでゲームを始めてコードかQRコードを共有。友だちは自分のスマホで参加します。
  • 1台のスマホで: 順番にスマホを回せば、家族みんなで1台で遊べます。
