같은 그림 찾기 (Memory Match)

▶ 지금 무료로 플레이

  • 👥 2–4 명
  • 종이와 펜 게임
  • 🆓

한국어 가이드

두 장을 뒤집고 기억하세요. 짝은 기억력이 가장 좋은 사람 차지.

English name: Memory Match

하는 방법

  1. 내 차례에 카드 두 장을 눌러서 뒤집어요. 모두에게 보여요.
  2. 짝이 맞으면 그 짝을 가져가고 한 번 더 해요.
  3. 안 맞으면 다음 사람 차례가 시작될 때 다시 뒤집히고, 차례가 넘어가요.

점수

짝 하나에 1점이에요.

이기는 방법

짝을 모두 찾으면 짝이 가장 많은 사람이 이겨요. 모두 같으면 비겨요.

자주 묻는 질문

컴퓨터가 속임수를 쓰나요?

아니요. 뒤집힌 카드만 알고, 그중 몇 개는 잊어버리기도 해요.

짝은 몇 개인가요?

카드 스물네 장에 짝 열두 개예요.

플레이 방법

  • 게스트로: 가입도 로그인도 없이 이름만 고르고 바로 플레이.
  • 컴퓨터와: 아무도 없으면 빈자리는 컴퓨터가 채워요. 쉬움, 보통, 어려움 중에서 선택.
  • 온라인으로: 전 세계 플레이어가 있는 공개 테이블에 앉아 보세요.
  • 가까운 친구와: 휴대폰 한 대로 게임을 열고 코드나 QR 코드를 공유하면 친구들이 각자 휴대폰으로 참여해요.
  • 휴대폰 한 대로: 차례대로 휴대폰을 넘기면 가족 모두가 한 대로 즐길 수 있어요.
