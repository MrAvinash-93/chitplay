숫자 기억력 테스트 (Number Memory)

▶ 지금 무료로 플레이

  • 👥 1–4 명
  • 종이와 펜 게임
  • 🆓

한국어 가이드

숫자가 잠깐 보였다 사라져요. 다시 입력하세요. 라운드마다 한 자리씩 길어져요: 몇 자리까지 기억할까요?

English name: Number Memory

하는 방법

  1. 숫자가 잠깐 나타나요. 아래 막대가 얼마나 남았는지 보여 줘요.
  2. 사라지면 키패드(또는 키보드)로 숫자를 입력하고 ✓를 눌러요. 최대 15초예요.
  3. 맞히면 다음 숫자는 한 자리 길어져요. 틀리면 하트 하나를 잃고, 셋을 잃으면 탈락이에요.
  4. 입력은 각자 휴대폰에 남고 ✓를 누르면 답 전체가 보내져요. 답하는 동안 친구 휴대폰에는 숫자가 보내지지 않아요.

점수

정답은 한 자리마다 10점이에요(7자리면 70점). 70, 150, 250, 400점에서 메달을 받아요.

이기는 방법

혼자라면 기억할 수 있는 가장 긴 숫자에 도전해요. 친구와 하면 점수가 가장 많은 사람이 이겨요. 모두 탈락하거나 마지막 남은 사람이 이미 1등이면 끝나요.

자주 묻는 질문

사람들은 보통 몇 자리를 기억하나요?

대략 일곱 자리, 두 자리 정도 차이가 나요. 연습하고 묶어서 외우면 열 자리 이상도 가능해요.

친구가 숫자를 보고 속일 수 있나요?

아니요. 답하는 동안 다른 휴대폰에는 숫자 대신 점이 보내져요.

플레이 방법

  • 게스트로: 가입도 로그인도 없이 이름만 고르고 바로 플레이.
  • 컴퓨터와: 아무도 없으면 빈자리는 컴퓨터가 채워요. 쉬움, 보통, 어려움 중에서 선택.
  • 온라인으로: 전 세계 플레이어가 있는 공개 테이블에 앉아 보세요.
  • 가까운 친구와: 휴대폰 한 대로 게임을 열고 코드나 QR 코드를 공유하면 친구들이 각자 휴대폰으로 참여해요.
  • 휴대폰 한 대로: 차례대로 휴대폰을 넘기면 가족 모두가 한 대로 즐길 수 있어요.
