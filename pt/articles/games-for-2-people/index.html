Jogos para 2 pessoas

Atualizado: 2026-11-14

Dois jogadores é o número perfeito para uma disputa de verdade: ninguém para se esconder atrás e cada jogada conta. Seja para pensar muito ou rir rápido, existe um jogo para dois.

Estes são os melhores jogos para dois, da estratégia de sempre aos duelos rápidos, frente a frente ou online.

Jogos clássicos para jogar em qualquer lugar

  • Guerra de polegares

    Entrelace os dedos com o adversário e tente prender o polegar dele enquanto conta até três.

    👥 2 jogadores · Você precisa de: nada

  • Pedra, papel e tesoura

    Contem até três e mostrem um gesto: pedra quebra tesoura, tesoura corta papel, papel embrulha pedra. Melhor de cinco.

    👥 2 jogadores · Você precisa de: nada

  • Vinte perguntas

    Um jogador pensa numa pessoa, animal ou objeto. Os outros fazem até vinte perguntas de sim ou não para descobrir.

    👥 2+ jogadores · Você precisa de: nada

Dicas

  • Alternem quem começa a cada partida, já que a primeira jogada costuma ser vantagem.
  • Joguem melhor de três para compensar uma vitória de sorte.
  • Depois de uma partida longa, uma rápida mantém o clima.

Perguntas

Qual o melhor jogo para duas pessoas?

Xadrez, Carrom e Damas são os grandes clássicos; para algo mais rápido, experimente Lig 4 (Four in a Row) ou Ship Fight no ChitPlay.

Duas pessoas podem jogar online em celulares diferentes?

Sim. No ChitPlay um jogador cria a sala e o outro entra com o código ou link, de onde estiver.
