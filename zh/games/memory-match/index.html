记忆翻牌 (Memory Match)

▶ 立即免费玩

  • 👥 2–4 人
  • 纸笔游戏
  • 🆓

中文指南

翻两张牌记住位置，配对归记性最好的人。

English name: Memory Match

玩法

  1. 轮到你时，点两张牌翻开。所有玩家都看得到。
  2. 如果配对，你拿走这一对并再翻一次。
  3. 如果不配对，下一位玩家开始时它们会翻回去，轮到下一个人。

计分

每一对 1 分。

怎样获胜

全部配对找到后，配对最多的人获胜。大家一样多就是平局。

常见问题

电脑玩家会作弊吗？

不会。它们只知道已经翻开过的牌，而且还会忘掉一些。

一共有几对？

二十四张牌，十二对。

玩法

  • 游客模式: 不用注册，不用登录。选个名字马上开玩。
  • 和电脑玩: 没人的时候，空位由电脑玩家补上。可选简单、普通、困难。
  • 在线玩: 坐到公开桌，和来自世界各地的玩家对战。
  • 和身边的朋友玩: 在一部手机上开局，分享房间码或二维码，朋友用自己的手机加入。
  • 一部手机轮流玩: 手机轮流传：一部手机就够全家一起玩。
