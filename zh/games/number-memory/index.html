数字记忆测试 (Number Memory)

▶ 立即免费玩

  • 👥 1–4 人
  • 纸笔游戏
  • 🆓

中文指南

一个数字闪现后消失，把它输回来。每回合多一位：你能记住几位？

English name: Number Memory

玩法

  1. 一个数字会出现片刻。下面的进度条显示它还会停留多久。
  2. 数字消失后，在数字键盘（或电脑键盘）上输入并按 ✓。你最多有 15 秒。
  3. 答对：下一个数字多一位。答错：失去一颗心。三颗心都没了就出局。
  4. 每部手机保存自己玩家的输入，按 ✓ 时发送完整答案；作答期间朋友的手机不会收到这个数字。

计分

答对每一位得十分：7 位数得 70 分。70、150、250、400 分可获得奖牌。

怎样获胜

一个人玩时，挑战你能记住的最长数字。和朋友一起时分数最多的人获胜；所有人出局，或最后剩下的人已经领先时，游戏结束。

常见问题

大多数人能记住几位数字？

大约七位，上下差两位。通过练习和分组记忆的技巧，可以记到十位甚至更多。

朋友能偷看数字作弊吗？

不能。作答期间，其他手机收到的是圆点，而不是数字。

玩法

  • 游客模式: 不用注册，不用登录。选个名字马上开玩。
  • 和电脑玩: 没人的时候，空位由电脑玩家补上。可选简单、普通、困难。
  • 在线玩: 坐到公开桌，和来自世界各地的玩家对战。
  • 和身边的朋友玩: 在一部手机上开局，分享房间码或二维码，朋友用自己的手机加入。
  • 一部手机轮流玩: 手机轮流传：一部手机就够全家一起玩。
